Setup Guide

Overview

This dashboard shows a live view of the OpenPMU sampled-value (SV) stream, published over MQTT and forwarded to the browser over a WebSocket connection.

Step 1. Start the pipeline

Make sure Mosquitto, WaveMU, and ADCtoMQTT are all running before starting this dashboard. The connection indicator will show Reconnecting... until frames start arriving.

Step 2. Reading the chart

Drag on the chart to zoom into a time range. Double-click, or use Reset Zoom, to return to the live window.

Control Effect
Pause / Resume Freezes the chart on the current view. Data keeps arriving in the background.
Drag on chart Zoom into the selected time range.
Reset Zoom Return to the full live scrolling window.
Channel checkboxes Show or hide individual channel traces.

Channels appear automatically as soon as the first frame containing them is received.
